PR Summary: Firebase integration and demo

Branch: worksheet-8

What this PR does:
- Adds Firebase core and common Firebase packages (`firebase_core`, `firebase_auth`, `cloud_firestore`, `firebase_analytics`).
- Initializes Firebase in `lib/main.dart` using `DefaultFirebaseOptions` (generated by FlutterFire CLI) with safe fallback handling.
- Adds `lib/firebase_options.dart` (generated) and `lib/firebase_example.dart` (small helper for Auth/Firestore usage).
- Adds a `Firebase Demo` button to `OrderScreen` that signs in anonymously and writes a demo order to Firestore.
- Adds a `Firebase Orders` screen that streams and displays orders from Firestore.
- Adds Android Gradle plugin/classpath edits to process `google-services.json`.
- Removes raw downloaded SDK config files from the repo (keeps only the generated `firebase_options.dart`).

Notes & manual steps required after merging:
1. Register Android/iOS/web apps in your Firebase console (or keep the generated project if you used the FlutterFire CLI here).
2. Place `google-services.json` in `android/app/` and `GoogleService-Info.plist` in `ios/Runner` locally (do not commit these files to source control).
3. Enable Windows Developer Mode to run desktop with plugins:
   - Open Settings → For developers → Toggle Developer Mode.
4. Optionally re-run `flutterfire configure` on your machine if you want to regenerate `lib/firebase_options.dart` for another Firebase project.

Testing:
- The demo was run on Chrome in this environment; pressing `Firebase Demo` signs in anonymously and creates a document in the `orders` collection.
- Running on Windows requires Developer Mode; `flutter run -d windows` failed in this environment until Developer Mode is enabled.
